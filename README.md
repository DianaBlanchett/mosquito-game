昨天晚上打蚊子打到凌晨4点半也没找到，于是弄了两个蚊子网页游戏。

<br>

这是两个问了ChatGPT然后用 HTML / CSS / JavaScript 制作的蚊子小游戏，打开网页就可以玩。

<br>

游戏1：蚊子模拟器 （就是那个index.html）或者点这个：https://dianablanchett.github.io/mosquito-game/

人会随机出现在屏幕上的不同位置

用鼠标拖动蚊子即可咬人

蚊子会逐渐变大

当蚊子大到几乎占满整个屏幕时，会出现特殊提示

可以自定义人头顶显示的名字，也可以选择不显示名字

<br>

游戏2：打蚊子模拟器 （就是那个打蚊子模拟器.html）

随机出现蚊子

点击蚊子获得分数

没有限制，就是点屏幕打发时间
